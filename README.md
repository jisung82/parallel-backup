# Parallel Backup

Windows에서 사용하는 GUI 기반 병렬 백업 프로그램입니다.

## 핵심 기능

- 하나의 원본 폴더를 여러 경로에 동시에 백업
- 백업 이름 + 날짜/시간 자동 생성
  - 예: `uni_mcp_20260921_193000`
- **증분 백업**
  - 각 백업 대상에서 가장 최근의 **검증 완료 스냅샷**을 기준으로 비교
  - 변경되지 않은 파일은 가능한 경우 NTFS 하드링크로 재사용
  - 하드링크가 불가능한 환경에서는 자동으로 일반 복사
  - 신규/변경 파일만 실제 데이터를 다시 복사
- **SHA-256 무결성 검사**
  - 백업 후 모든 파일의 SHA-256을 원본 기준값과 비교
  - 불일치/누락 파일이 있으면 해당 백업을 검증 실패로 처리
- 백업마다 `.parallel-backup/manifest.json` 저장
  - 원본 경로
  - 파일별 SHA-256
  - 파일 크기
  - 수정 시간
  - 복사/재사용 통계
  - 검증 상태
- 여러 대상에 대한 병렬 처리
- 진행률 및 로그 표시
- 원본 내부 경로를 백업 대상으로 지정하는 실수 방지

## 실행

Python 3.10 이상 권장.

```powershell
python app.py
```

외부 Python 패키지는 필요하지 않습니다.

## 기본 사용 예

원본:

```
C:\ai\uni_mcp
```

백업 이름:

```
uni_mcp
```

백업 대상:

```
D:\Backups
E:\Backups
F:\Backups
```

실행 결과:

```
D:\Backups\uni_mcp_20260921_193000
E:\Backups\uni_mcp_20260921_193000
F:\Backups\uni_mcp_20260921_193000
```

세 대상은 동시에 처리됩니다.

## 증분 백업 동작

첫 백업은 기준 스냅샷이 없으므로 전체 파일을 복사합니다.

두 번째 이후에는 각 대상 경로에서 같은 백업 이름을 가진 가장 최근의 **검증 완료** 백업을 찾습니다.

예:

```
D:\Backups\
├─ uni_mcp_20260921_193000
├─ uni_mcp_20260921_221500
└─ uni_mcp_20260922_090000
```

새 백업에서 변경되지 않은 파일은 이전 스냅샷의 파일을 하드링크로 재사용할 수 있습니다. 따라서 같은 볼륨의 NTFS 환경에서는 중복 데이터 생성을 크게 줄일 수 있습니다.

## 무결성 검사

기본값은 SHA-256 검증 ON입니다.

백업 후 다음을 확인합니다.

1. 모든 예상 파일이 존재하는지 확인
2. 대상 파일을 다시 SHA-256으로 계산
3. 원본에서 계산한 SHA-256과 비교
4. 하나라도 불일치하면 검증 실패

검증에 성공한 백업만 다음 증분 백업의 안전한 기준으로 사용됩니다.

## 주의

- 백업 대상은 원본 폴더 내부에 두지 않는 것이 필수입니다.
- 백업 대상의 이전 백업 파일을 직접 수정하면 다음 증분 백업의 하드링크 재사용에 영향을 줄 수 있습니다. 최종 무결성 검사는 이를 탐지합니다.
- 백업용 드라이브의 파일시스템/권한에 따라 하드링크를 사용할 수 없을 수 있으며, 이 경우 자동으로 일반 복사로 전환됩니다.

## 향후 확장

- 파일 변경 감지 캐시로 대규모 프로젝트의 해시 계산 최적화
- 백업 취소/일시정지
- 제외 패턴
- 압축 백업
- 자동 백업 스케줄러
- Windows `.exe` 배포
- 복구/Restore 기능
